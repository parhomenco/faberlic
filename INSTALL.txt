БУМЕРАНГ — версия для обычного хостинга без базы данных

УСТАНОВКА
1. Распакуйте архив на компьютере.
2. Загрузите всё содержимое папки, включая assets, images, index.html, index.php и .htaccess, в нужную папку хостинга.
3. Откройте адрес этой папки. Если хостинг не выбирает стартовый файл автоматически, откройте index.php или index.html явно.
4. Никакие пароли, MySQL, SQL-импорт, Composer, Node.js и команды на хостинге не нужны.
5. Локально откройте index.html двойным щелчком. index.php работает только через сервер PHP.

ПЕРЕНОС В ПОДПАПКУ
Все локальные изображения, CSS, JS и иконки имеют относительные пути.
Можно перемещать всю папку целиком, в том числе в несколько вложенных папок.
Ссылки на Faberlic, обучающие видео и медицинские источники оставлены внешними: для них нужен интернет.

БЕЗ БАЗЫ ИЛИ MYSQL?
Эта версия не использует базу: каталог включён в готовые файлы, расчёты работают в браузере. Интерфейс и исходная логика сохранены.
Ответы анкеты и «Мой набор» существуют только в открытой вкладке. После перезагрузки они сбрасываются, как в исходном сайте. localStorage и cookies для хранения ответов не используются.
PDF и PNG формируются на устройстве. HTTPS рекомендуется для буфера обмена и системного меню «Поделиться»; если меню недоступно, используется скачивание. Работа с локальными файлами зависит от ограничений браузера.
MySQL понадобится, если появятся личные кабинеты, сохранённые анкеты, история заказов, общая админ-панель и редактирование каталога без пересборки. Тогда нужна отдельная серверная реализация с авторизацией и защитой персональных данных. В этом архиве её нет.
Наличие MySQL в тарифе хостинга не означает, что сайт должен его использовать. Для текущего сайта вариант без базы проще в установке и не хранит чувствительные ответы на сервере.

ИЗМЕНЕНИЯ
Не изменяйте минифицированный assets/app.js вручную. Исходники и воспроизводимая команда build:hosting остаются в проекте v0; для запуска на хостинге они не требуются.
Папку со сборкой не нужно делать доступной для записи PHP. Сайт не создаёт файлы на сервере.
Apache: .htaccess задаёт стартовый файл и базовые заголовки. На Nginx настройку стартового index при необходимости делает хостер. Rewrite-правила и фиксированный домен не требуются.
